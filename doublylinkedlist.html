Что такое двусвязный список?

Двусвязный список — это структура данных, состоящая из узлов (элементов), где каждый узел хранит ссылку не только на следующий элемент, но и на предыдущий. Это делает возможным перемещение как вперед, так и назад по списку.

Принцип работы:

  • Каждый узел содержит данные и две ссылки:
    • next — указывает на следующий узел.
    • prev — указывает на предыдущий узел.
  • Добавление элемента возможно как в начало, так и в конец списка.
  • Удаление элемента требует корректировки ссылок next и prev.
  • Перебор списка возможен в обоих направлениях.

// Узел (элемент) двусвязного списка
class Node<T> {
    var value: T  // Хранимое значение
    var next: Node?  // Ссылка на следующий узел
    weak var prev: Node?  // Слабая ссылка на предыдущий узел (чтобы избежать утечки памяти)
    
    init(value: T, next: Node? = nil, prev: Node? = nil) {
        self.value = value
        self.next = next
        self.prev = prev
    }
}
