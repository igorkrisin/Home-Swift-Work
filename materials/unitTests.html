✅ Что такое Unit Test в Swift?

Unit-тесты (модульные тесты) проверяют работу отдельных функций или классов изолированно. Они помогают убедиться, что каждый компонент работает правильно.

🛠 Основы Unit Testing в Swift

Для написания тестов используется XCTest. В Xcode можно создать Unit Testing Target, и он автоматически подключит этот фреймворк.

🔍 Пример теста:

    
    import XCTest
    @testable import YourApp // Импортируем основное приложение для тестирования

class MathTests: XCTestCase {
    func testSumm() {
        let result = summ(a: 2, b: 3)
        XCTAssertEqual(result, 5, "Функция summ работает неверно")
    }
}

💪 Основные команды:

  • XCTAssertEqual(a, b) – Проверяет, что a == b
  • XCTAssertTrue(condition) – Проверяет, что условие true
  • XCTAssertFalse(condition) – Проверяет, что условие false
  • XCTAssertNil(object) – Проверяет, что объект nil
  • XCTAssertNotNil(object) – Проверяет, что объект не nil

🚀 Как запустить тесты?

  1. Открыть Xcode
  2. Перейти в Product → Test (Cmd + U)
  3. Смотреть результаты в Test Navigator (⌘+6)

🔄 Тестирование асинхронного кода

        
        func testAsyncFunction() async {
            let result = await someAsyncFunction()
            XCTAssertEqual(result, expectedValue)
        }
