✅ Что такое Unit Test в Swift?

Unit-тесты (модульные тесты) проверяют работу отдельных функций или классов изолированно. Они помогают убедиться, что каждый компонент работает правильно.

🛠 Основы Unit Testing в Swift

Для написания тестов используется XCTest или Testing. В Xcode можно создать Unit Testing Target, и он автоматически подключит этот фреймворк.

Unit-тестирование в Swift

Unit-тестирование — это процесс проверки отдельных модулей кода, таких как функции или классы, чтобы убедиться, что они работают корректно.

Тестирование с XCTest

XCTest — стандартный фреймворк для тестирования в Xcode. Основные компоненты:

  • XCTestCase — базовый класс для тестов.
  • setUp() и tearDown() — методы, выполняемые перед и после тестов.
  • XCTAssert — функции для проверки условий.

Пример теста с XCTest

import XCTest
@testable import myProject 

final class StackTests: XCTestCase {
    func testAppendMult() {
        var stack = Stack()
        stack.appendMult([3, 2, 4.6], isReverse: false)

        XCTAssertEqual(stack.showStack(), [3, 2, 4.6], "Стек должен содержать 3, 2, 4.6")

        stack.pop()
        XCTAssertEqual(stack.showStack(), [3, 2], "После pop стек должен содержать 3, 2")

        stack.appendMult([1.5], isReverse: true)
        XCTAssertEqual(stack.showStack(), [1.5, 3, 2], "Стек должен добавляться в обратном порядке")
    }
}

Запуск тестов

Тесты запускаются в Xcode:

  • Нажмите ⌘ + U, чтобы запустить все тесты.
  • Откройте вкладку Test Navigator (⌘ + 6), чтобы увидеть результаты.

Тестирование с Testing

Swift также поддерживает import Testing для модульного тестирования.

import Testing

struct TestingUnit {
    @Test func example() {
        #expect(summ(a: 2, b: 3) == 5)
    }
}

Этот метод позволяет писать тесты более декларативно.
